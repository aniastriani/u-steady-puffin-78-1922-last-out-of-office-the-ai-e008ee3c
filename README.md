a barista — machine habits turned to coffee, funny on a first cold read.

## Run it

```sh
python3 main.py
```

The program writes one line (212 characters) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Pure standard library, deterministic:
the same bytes on every run.
